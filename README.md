# 🎨 Color Palette Generator

A Color Palette Generator built using React.js that enables users to generate and explore different color shades from a selected base color. The application provides an intuitive interface for designers and developers to discover color variations and quickly copy color codes for their projects.

---

## 🚀 Features

### 🎨 Color Generation

* Generate Multiple Color Shades
* Create Color Variations from a Base Color
* Dynamic Color Rendering
* Real-Time Color Updates

### 📋 Color Management

* Display Color Codes
* Copy Color Values to Clipboard
* Easy Color Selection
* Instant Visual Preview

### ⚛️ React Functionality

* Component-Based Architecture
* State Management with React Hooks
* Dynamic UI Rendering
* Efficient User Interactions

### 🎨 User Interface

* Clean and Modern Design
* Responsive Layout
* Interactive User Experience
* Easy Navigation

## ▶️ How to Run

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm start
```

4. Open the application in your browser and generate color palettes.
